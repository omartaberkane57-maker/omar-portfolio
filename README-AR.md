# Omar Taberkane Portfolio — Ready to Upload

## Structure
- `index.html` — الصفحة الرئيسية
- `styles.css` — التصميم
- `script.js` — التفاعل والمعرض وتبديل اللغة
- `assets/images/` — الصور
- `assets/videos/` — الفيديوهات

## طريقة التحديث على GitHub Pages
1. افتح مستودع `omar-portfolio`.
2. استبدل `index.html` و`styles.css` و`script.js`.
3. ارفع مجلدي `assets/images` و`assets/videos` كاملين.
4. حافظ على أسماء الملفات والمجلدات كما هي.
5. انتظر تحديث GitHub Pages ثم افتح الموقع.

## أين تضيف صورًا جديدة؟
ضع الصور داخل:
`assets/images/`

يفضل:
- JPG أو WebP للصور.
- PNG للشعارات أو الصور ذات الخلفية الشفافة.
- صور واضحة، ويفضل عرض 1200px أو أكثر للأعمال الرئيسية.

## أين تضيف فيديوهات؟
ضع MP4 داخل:
`assets/videos/`

يفضل ضغط الفيديو إلى 1080p أو 720p حتى يبقى الموقع سريعًا.

## ملاحظة مهمة
قبل نشر صور الشهادات، يفضل إخفاء أرقام التسجيل، تاريخ الميلاد، وأي بيانات شخصية لا يحتاجها صاحب العمل.
